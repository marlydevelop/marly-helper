## Суть
Личное десктоп-приложение автора для моддинга GTA 5 RP (Windows, Electron). Вкладки: Гайды (подпись «База знаний»), Склад (бывш. «Фишки», id `tips`, закрыт заглушкой `wip()`), Главная, Инструменты, Настройки. Телеграм автора: t.me/marlyhelper. Логотип «MH».

## Стек и формат
Electron 33, без фреймворков и сборщиков, Node.js LTS. Запуск: `start.bat` (или `start-debug.bat`, `npm install && npm start`), сборка: `build-exe.bat` / `npm run dist` (portable, `dist/`), установщик: `build-setup.bat` (`installer/`, ставит в `%LOCALAPPDATA%\Programs\Marly Helper`, папка всегда «Marly Helper», по умолчанию en + тёмная, ключ `mhs2`).
- Главный процесс: `main.js` (окно, лог, тема, IPC), `preload.js` (`window.api`, contextIsolation, sandbox). Модули инструментов: `dds.js`, `svg.js`+`svgpost.js`, `up.js`, `rm.js`, `ret.js`, `core.js`, `tc.js`, `gs.js`, `cw.js`+`cwx.js`+`rpf.js`+`rpfhashes.json`+`rpfmagic.dat`+`rpfenc.bin`+`tex.js`+`ytd.js`+`drawable.js`. Бинарники в `bin/` (texconv, vtracer, mhconv/), едут через extraResources.
- UI: `src/index.html` (HTML+CSS+JS), `src/tool-*.js` (по файлу на инструмент, свой словарь ru/uk/en, регистрируют `window.TOOLS`), `src/lib/` (`upcore.js`, `imagetracer.js`), `src/fonts/` (Unbounded, Manrope), `src/hud_reticle.gfx`.
- IPC окна: `win:min|max|close|ismax`, событие `win:state`, `theme:set`, `app:wipe` (TEMP). `window.api`: `setTheme`, `winMin/Max/Close/IsMax`, `onWinState`, `wipe` и API инструментов.
- Лог ошибок `%APPDATA%\marly-helper\log.txt`, тема до загрузки `userData/theme.json`.
- Проверка без Electron: Playwright (Chromium) по `src/index.html` со стабом `window.api`; перед этим `localStorage.setItem('mh1',JSON.stringify({setup:1}))` и ждать ~4.5 с (заставка). Синтаксис: `node --check`. Electron и Windows в песочнице не запускаются.

## Функции (сделано, детали искать в коде)
- **PNG→DDS** (`dds.js`, `tool-dds.js`, IPC `dds:*`, `mh_dds`): texconv, реальный предпросмотр, все опции, пакет до 200, дубли имён `_1`.
- **PNG→SVG** (`svg.js`, `svgpost.js`, `tool-svg.js`, IPC `svg:*`, `mh_svg2`): движок vtracer CLI (`bin/vtracer.exe` или `userData/bin`, сам качается с sha256; `get-vtracer.bat`), пресеты sharp/balanced/detailed/bw, фон/прозрачность, режим Blender (`<имя>_blender.py`, v8.75). Старый ImageTracer в `src/lib/` частично устарел: сверять с кодом.
- **Улучшение фото** (`up.js`, `tool-up.js`, `lib/upcore.js`, IPC `up:*`, `mh_up`): классические алгоритмы в Web Worker (`UPFactory.toString()`, внутри нельзя ссылаться на внешние переменные), предпросмотр фрагмента 720 px, лимит 64 Мп.
- **Удаление фона** (`rm.js`, `tool-rm.js`, IPC `rm:*`, `mh_rm`): U2-Net ONNX (`onnxruntime-node` 1.31.1, CPU), модель 176 МБ качается в `userData/models` с sha256.
- **Прицел** (`ret.js`, `tool-ret.js`, IPC `ret:*`, `mh_ret`): правка `src/hud_reticle.gfx`: картинки tag 36 + шейпы + цвета в байткоде `HUD_RETICLE` (`patchColours`, пишутся обычные r,g,b,a без вычитания, v8.10), `vis` instant/stay. Формат (v8.111, `fmt` vec|img, по умолчанию vec): вектор = настоящие фигуры вместо картинки, см. Лог v8.111.
- **Core** (`core.js`, `tool-core.js`, IPC `core:save`): правка `EffectRuleDictionary` core.ypt-XML ПО ТЕКСТУ (`index/model/build`), «Скрыть от стрелка» (LOD), `loopOn`. Текстуры (v8.100): в блоке под-партикла показывается и правится `TextureName` его ParticleRule (`pindex`, `texVars`, `patchTex`, `texSet` в `tool-core.js`, ключи правок `t<n>.<k>`); ParticleRuleDictionary меняется только по этим тегам. Режимы (v8.101): вкладки Effect / Particle / Emitter rule в поиске (`mode`), у двух новых общий редактор полей: `rindex` (список правил словаря), `rleaves` (поля: value int/hex/num/bool, векторы, `KeyframeTime/Value`; секции `sec`, подгруппы `sub`/`kfp`), `patchLeaves`, состояние `rmods{prt,emt}`/`rcur`/`rcurs`, ключ правки = индекс поля, `build(...,rm,rix)` складывает патчи одного правила (сначала поля, потом размер «вблизи»/текстура: они перебивают ту же ячейку). Секции рисуются лениво (`details[data-rsec]`, `fillSec`), цвет-пикер у KFP с `rgb` в имени. НЕ правятся: Name, RefCount, RandomIndex, ShaderVarID, Type, DomainType, FileVersion, TextureName (она в Effect), EvolutionList, Drawables. Имена полей в правилах = теги XML (не переводятся).
- **Таймциклы** (`tc.js`, `tool-tc.js`, id `tc`, IPC `tc:save`): копии `<cycle name>` под 17 типов погоды, файл `w_<имя без _>.xml`.
- **Settings** (`gs.js`, `tool-gs.js`, id `gs`, IPC `gs:save`): правка GTA V `settings.xml` по тексту, таблица `FIELDS`, пресеты `PRESETS` (max/light/mid/beauty; ключ с точкой = полный id, без точки = `graphics.*`), оценка нагрузки.
- **Color Picker** (`tool-cp.js`, id `cp`): без IPC, 11 кодов (HEX, float 0-1 для таймциклов, `0xAARRGGBB` и др.), пипетка `EyeDropper`, CSS инжектится сам.
- **RPF Explorer** (id `cw`, `cw.js`, `rpf.js`, `tool-cw.js`, `.rx-*`, IPC `cw:*`): нативный движок RPF7 (ключи как у CodeWalker: AES из `gta5.exe` + `rpfmagic.dat`), поиск по индексу, просмотр (текст/hex/картинка/.ytd/3D .ydr/.ydd/.yft), правка (замена, добавление, переименование, удаление, mkdir, создание RPF, «Оптимизировать», «Пофиксить» = NG-шифр оглавления через `rpfenc.bin`), drag&drop туда и сюда, мультивыделение, текстовый редактор, редактор .ytd (`ytd.js`), XML-конвертер `bin/mhconv/mhconv.exe` (вызов CodeWalker.Core.dll; экспорт/импорт, расхеширование через `strings.txt` копии, пакетный экспорт), отдельное окно (`cwx.js`, второй процесс `--explorer`). Известно: NG-запись, `.ysc`, Enhanced-ключи, анимации/скиннинг в 3D НЕ сделаны.

## Автообновление (v8.115)
`update.js` (в `build.files`, подключается в `main.js` через `loadTool`/`initTool`, в окне проводника `--explorer` выключен). Константы `REPO` ('marlydevelop/marly-helper', публичный) и `ASSET` ('Marly-Helper-update.zip') в начале файла. Через 2.5 с после старта GET `api.github.com/repos/REPO/releases` (берётся самый новый не-draft релиз с этим asset, prerelease допустимы), сравнение с `app.getVersion()` (`cmpVer`, beta старше релиза). Хэш sha256 обязателен: `asset.digest` или рядом `<ASSET>.sha256`. Ставит только установленная версия (packaged, не portable, папка приложения доступна на запись); иначе только лог. IPC: `upd:get`, `upd:start`, событие `upd:state` ({phase idle|available|downloading|installing|error, version, pct}); `window.api.updGet/updStart/onUpd`. Окно (`index.html`, `UPD`, `updApply`): после заставки и первого запуска показывает баннер `.upd` сверху (стиль темы и стекла, тексты `updA/updD/updI/updE/updV` ru/uk/en), ровно через 5 с зовёт `updStart`. Дальше main: скачивание во `%TEMP%\mh-update-<ver>` -> sha256 -> `tar -xf` (запасной Expand-Archive) -> проверка exe+app.asar -> `apply.ps1` (ASCII, пути параметрами): ждёт выход программы, гасит процессы из папки установки (окно проводника), robocopy поверх, обновляет DisplayVersion в реестре, запускает exe; при сбое копирования запускает старую версию, лог `%TEMP%\mh-update.log`. Выпуск релиза: поднять `version` в `package.json`, `make-update.bat` (-> `dist/update/` zip + .sha256), на GitHub релиз с тегом `v<version>` и этими двумя файлами. Файлы, которых нет в новой версии, не удаляются (без /MIR).
